# devctl v0.1.0

首个独立 devctl 版本：在 Windows 原生启动 JDK 21 / Spring Boot 微服务，将本地浏览器或 Postman 请求发送到本地 JVM，并访问共享 Kubernetes 的 API 和中间件。管理员在已有 namespace 部署共享接入组件；开发者无需创建个人 namespace 或业务副本。

## 功能

- Go 标准库 CLI，提供 doctor、validate、connect、run、stop、test、probe、status、disconnect 和 JSON 输出，适合 IDE 与 AI Agent 调用。
- 两种接入后端：Telepresence；或 kubectl / SSH + Chisel + sing-box。SSH 模式下 Kubernetes 凭据保留在远端。
- 按允许清单读取 Deployment、ConfigMap、Secret，准备本地环境变量和配置文件快照。
- 后台管理本地 JVM 与隧道，支持健康检查、测试退出码、日志脱敏及 Windows 进程树清理。
- 提供已有 namespace 的 Helm 部署模板、启动清单、IDE 示例、PowerShell 验收脚本和中文文档。

## 下载与使用

Windows x64 下载 `devctl-windows-amd64.zip`，Windows ARM64 下载 `devctl-windows-arm64.zip`。压缩包包含 devctl.exe、文档、示例、部署模板、脚本及包内 SHA256SUMS。Release 同时提供单独 EXE、Linux amd64 二进制和附件 SHA256SUMS。

devctl 无需安装 Go、Docker、WSL、Python 或 Node.js。JDK、构建依赖及所选后端工具仍需单独准备；附件不包含 Telepresence、Chisel、sing-box 或其容器镜像。请先阅读包内 README.md 和 docs/admin.md，按实际集群修改示例配置。

## 验证与已知范围

- 已通过 Go 单元与 CLI 集成测试、`go test -race ./...`、`go vet ./...`。
- 已使用 Helm 和 sing-box 官方二进制验证 Chart 渲染与生成配置。
- 已完成 Windows amd64 / arm64 和 Linux amd64 构建；集成测试的集群侧工具使用测试替身。
- 尚未完成真实 Windows 11、企业 VPN、Kubernetes 1.34 / Istio 1.28.3 ambient 及实际中间件验收；本次发布不表示这些组合已经验证通过。
- Gateway v1 仅代理 IPv4 TCP 应用流量，DNS 使用专用 TCP 通道；消费者、定时任务和数据库迁移的本地行为必须按服务配置审查。

此版本使用独立标签 `devctl-v0.1.0`，不替换仓库现有的 ldbg 发布系列。
