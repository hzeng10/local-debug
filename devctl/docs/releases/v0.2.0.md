# devctl v0.2.0

本版本补齐共享离线 Kubernetes 集群的管理员部署流程：在联网机器按 JSON 配置准备工具、Chart 和镜像，通过 SSH 传入 Linux 节点完成检查、安装、验证与开发者配置交付。开发者继续在 Windows 原生运行 JVM，通过共享集群访问 API 和中间件，无需创建个人 namespace。

## 新增功能

- `bundle prepare/verify`：按固定版本准备离线资源，验证上游校验信息，生成资源锁与 SHA256SUMS；部署时不联网下载。
- `admin discover/plan/apply/verify/export/remote`：发现配置引用、只读预检查、渲染安装计划、SSH 自动部署、连通性验证和开发者配置导出，支持 JSON 输出及 AI Agent 调用。
- 支持内网镜像仓库，以及向指定节点导入 containerd / Docker 镜像；检查节点架构、运行时和镜像可用性。
- 复用已有 namespace，限制 Telepresence 管理范围；检查 Istio ambient 前置条件，遇到不符合条件的配置时停止并报告。
- 复用已有凭据，支持重复部署和失败回退；提供受限权限的凭据交付文件。
- 新增 PowerShell 准备、远程部署及验收脚本，以及 Linux 离线部署入口。
- 完善版本、下载、配置字段和故障恢复文档；提供 kube-system 中 gde-adapter 访问 GaussDB / Redis / MinIO 的本地调测示例。

## 下载与使用

管理员推荐下载 `devctl-admin-kit.zip`；Windows 开发者按架构下载 `devctl-windows-amd64.zip` 或 `devctl-windows-arm64.zip`。三个包均包含文档、示例、脚本、部署模板以及 Windows / Linux amd64 / arm64 程序；根目录 devctl.exe 与所选 Windows 架构匹配，管理员包默认 x64。

Release 另提供四种架构的独立程序及附件 `SHA256SUMS`，ZIP 内也包含逐文件校验清单。请先阅读 `docs/admin.md`，按实际集群修改 `examples/admin/` 中的 JSON 配置，再在联网准备机运行 `scripts/prepare-offline.ps1`。

**管理员交付包不等于已备齐第三方资源的离线安装包。** 附件不包含第三方工具和容器镜像；必须提前完成 bundle prepare 和 verify，再传入离线集群。运行 devctl 不需要 Go、Docker、WSL、Python 或 Node.js；本地业务服务仍需要 JDK、构建依赖与实际业务配置。

## 验证与范围

- Go 单元、CLI 集成、竞争检测及静态检查；离线 vendored 构建。
- 使用测试替身覆盖安装、重复执行、失败回退、镜像导入、凭据保留和安全路径检查。
- 使用官方 Telepresence 2.31.0 Chart、Helm 3.17.3 和真实 devctl 子进程验证 Chart 渲染及 post-renderer；交付配置默认固定 Helm 3.19.0。
- 使用官方 sing-box 1.12.0 验证生成配置；构建 Windows / Linux amd64 / arm64，并校验交付包。
