# devctl v0.2.1

修复离线物料准备脚本的代理配置易用性与程序定位问题，并为下载失败补充实际连接路径提示。请同时更新 `scripts/prepare-offline.ps1` 和 devctl 程序。

## 修复内容

- 从当前 PowerShell 进程读取 HTTP_PROXY、HTTPS_PROXY、NO_PROXY，兼容小写，修剪空白并为 host:port 补齐 http://；仅设置 HTTP_PROXY 时用于 HTTPS 下载。
- 新增 `-Proxy` 显式覆盖和 `-NoProxy` 旁路配置，支持带用户名和密码的代理 URL。devctl 与 crane 继承同一组代理变量；脚本成功或失败后恢复调用窗口的环境。
- 默认优先使用交付包根目录或源码 dist 中的程序，避免 PATH 中旧版本被误调用；保留 `-Devctl` 显式指定。
- 下载日志显示每次请求及重定向实际走代理还是直连，补充认证、代理协议/端口和 CA 排查提示；日志隐藏代理用户信息和签名下载 URL，stdout 保持 JSON。
- 保留原生程序退出码，包括调用方启用 PowerShell 7 原生命令错误偏好的情况。

## 认证代理示例

```powershell
.\scripts\prepare-offline.ps1 `
  -Config .\examples\admin\bundle.local.json `
  -Proxy 'http://myuser:mypassword@proxy.example.com:8080'
```

端口替换为实际值。若现有 NO_PROXY 导致 GitHub 绕过代理，可追加 `-NoProxy ''`。用户名或密码含特殊字符时先分别 URL 编码，完整示例见 `docs/admin.md`。HTTPS 下载通常使用 http:// CONNECT 代理；仅代理监听端口本身支持 TLS 时才用 https://。

## 下载与验证

- 管理员使用 `devctl-admin-kit.zip`；Windows x64 / ARM64 分别使用对应 Windows ZIP。ZIP 包含程序、脚本、文档、配置示例和四种架构的独立程序。
- 同时提供 Windows / Linux amd64 / arm64 独立程序、附件 SHA256SUMS，以及 ZIP 内逐文件校验清单。
- 交付包不包含第三方工具和容器镜像；仍需在联网准备机完成 bundle prepare / verify，再传入离线环境。
- 已通过 Go 回归测试、竞争检测和静态检查；本地 HTTPS CONNECT 代理测试覆盖认证、重定向、NO_PROXY、环境变量大小写及子进程继承。
- 已在 Linux 上使用官方 PowerShell 7.4.7 执行脚本集成测试，覆盖环境读取、HTTP 代理回退、显式覆盖、程序选择、退出码、凭据脱敏和环境恢复；已构建四种架构程序。
- 保留官方 Helm / Telepresence Chart 和 sing-box 验证。尚未在真实 Windows 11 / Windows PowerShell 5.1 或用户现场代理、Kubernetes 集群中验收。
