# devctl v0.2.2

补齐 gde-adapter 及其它 Spring Boot 微服务的配置获取与精简指南，帮助开发者从已有集群和管理员交付资料中填写启动 JSON，复用项目自己的 application.yaml。

## 文档更新

- 逐项说明 gatewayDeployment、authEnv、fingerprint、routeCIDRs、bypassCIDRs、clusterDNS、fallbackDNS、envAllow、requiredEnv、overrides 等字段的来源与必填条件。
- 提供 Kubernetes、SSH 和 Windows PowerShell 查询命令，区分集群网络参数、管理员凭据交付、本机 VPN/DNS 和应用业务配置。
- 说明 Telepresence 与 Gateway 的可省略字段、Service/Pod 网段获取、Headless Service 和拓扑发现的路由要求。
- 说明已有 application.yaml 时无需重复配置 Spring 属性；分别处理环境变量占位符、ConfigMap/Secret 文件、local profile 和本地覆盖。
- 提供完整的精简 profile，并明确当前 envAllow 非空要求、后台任务审查、配置读取权限与实际业务验收范围。

从 README 或 docs/gde-adapter.md 进入新文档 `docs/gde-adapter-config.md`。本版本更新文档与版本标识；配置校验及运行行为与 v0.2.1 相同。

## 下载与验证

管理员使用 `devctl-admin-kit.zip`；Windows x64 / ARM64 使用对应 Windows ZIP。包内包含更新后的指南、脚本、配置示例和 Windows / Linux amd64 / arm64 程序；Release 另提供独立程序及 SHA256SUMS。

- 指南中的 PowerShell 示例通过语法解析，完整精简 profile 通过当前版本的 validate。
- Go 回归测试、竞争检测、静态检查及 PowerShell 脚本集成测试通过；保留官方 Helm / Telepresence Chart 和 sing-box 配置验证。
- 构建四种架构程序，并校验 ZIP 内容和 SHA256。

文档中的集群命令未在用户现场集群执行；未完成真实 Windows 11 / Windows PowerShell 5.1 和目标集群验收。管理员交付包仍不包含第三方工具和镜像，需要在联网准备机完成物料准备再传入离线环境。

使用独立标签 `devctl-v0.2.2`。
